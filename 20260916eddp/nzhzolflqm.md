# 脾氨肤在小儿支原体肺炎治疗中的价值

> 更新时间：2026-09-16 (UTC+8)

支原体肺炎是临床常见的小儿呼吸系统感染,肺炎支原体是该疾病的主要致病原, 轻者可导致患者发热, 呼吸困难, 肺炎支原体的传播途径主要为飞沫传播, 是人类易感微生物之一, 为介于病毒与细菌之间的一种病原微生物,D N A 和 R N A共存, 多见于儿童,主要临床表现为上呼吸道感染症状, 极易导致小儿肺炎,严重者可致死亡。

**脾氨肽口服溶液在小儿支原体肺炎治疗的临床研究：**

本组支原体肺炎患儿68例, 其中男41例, 女27例,年龄3-15岁，平均9.63±3.17岁, 均经血清ELISA(酶联免疫吸附试验)确诊, 排除存在严重肝、肾功能不全, 严重血液系统疾病、自身免疫性疾病、

其他呼吸道感染疾病和临床资料不全的患者。随机分为观察组和对照组各 34 例, 两组一般资料无统计学差异（P0.5）,有可比性。
