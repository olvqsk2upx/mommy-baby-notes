# 【学科发展】“研”出精彩 | 万能材料试验机

> 更新时间：2026-09-16 (UTC+8)

生物材料力学性能测试是医用材料学研究的重要内容，本期“研出精彩”栏目为大家介绍万能材料试验机，方便大家了解该型设备的基本情况、技术优势和应用现状。

**一、基本情况**

实验室配置的万能材料试验机为日本岛津公司生产的Auto Graph AGS-X型万能材料试验机。该仪器主机主要由工作台、操作面板、紧急停止开关、载荷传感器、限位杆、上下限位定位旋钮等组成。

**二、技术优势**

1. 载荷容量大，精度高
载荷容量为10KN，载荷精度显示值为±0.5%、±1%两种可选择（精度保证范围：0.2～100%），位置检测分辨率0.033μm，位置控制精度±0.1%，能够满足绝大多数医用生物材料的力学性能验证需求。
2. 试验速度可调范围大，精度高试验速度0.0001～1000mm/min，速度精度±0.1%，返回速度1500mm/min，数据采样间隔1ms。

**三、技术应用**

该型万能材料试验机在以下几个研究领域中应用广泛：1. 医用植入物材料的力学性能测试
医用植入物材料如镁合金、生物陶瓷、高分子材料等，在人体内需要承受复杂的力学环境。该型仪器能够模拟这些力学环境，对医用植入物材料进行拉伸、压缩、弯曲等多种力学性能测试，以评估其力学性能是否满足临床使用要求。
2. 生物材料的降解性能研究
该型仪器可以通过模拟体内的力学环境，研究生物材料在降解过程中的力学性能变化。这对于评估材料的降解速度、降解产物的安全性以及材料在降解过程中的生物相容性具有重要意义。
3. 组织工程材料的力学性能测试
该型仪器可以对水凝胶、支架等组织工程材料进行循环拉伸、循环压缩等力学性能测试，以评估其在模拟生理条件下的力学稳定性和耐久性。
4. 细胞力学研究细胞在生长和分化过程中会受到力学刺激的影响。该型仪器可以通过与细胞培养装置结合使用，对细胞施加特定的力学刺激，并观察细胞在力学刺激下的响应和变化。
